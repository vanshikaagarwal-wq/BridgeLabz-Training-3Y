ASSIGNMENT 1 Answer 1 -- Frontend development is the part of web development that focuses on the user interface, which includes everything users can see and interact with on a website, such as buttons, menus, text, images, and forms. It is mainly developed using HTML, CSS, and JavaScript. Backend development is the server-side part of a website that manages data, user authentication, and communication with databases. It is commonly developed using languages such as Java, Python, PHP, or Node.js. Full-stack development combines both frontend and backend development, allowing a developer to build an entire web application from start to finish. For example, on an online shopping website like Amazon, the product page is the frontend, the login verification and order processing are handled by the backend, and a full-stack developer can develop both parts of the application. The server receives the request and processes it. If the requested page requires data, the server retrieves it from the database. The server then sends the necessary files, such as HTML, CSS, JavaScript, images, and other resources, back to the browser. Answer 5 -- A web server is a software application or hardware system that stores website files and delivers them to users over the internet whenever they request a web page through a browser. It receives HTTP requests from clients, processes them, and sends back the requested content. Some of the most commonly used web servers are Apache HTTP Server, Nginx, Microsoft Internet Information Services (IIS), LiteSpeed, and Node.js with the Express framework. A static website displays the same content to every visitor because its pages are fixed and do not change unless manually updated by the developer. Static websites are simple, fast, and usually built using HTML and CSS. A personal portfolio website is an example of a static website. In contrast, a dynamic website displays different content based on user interaction, preferences, or database information. Dynamic websites use server-side programming languages and databases to generate content. Popular examples include Amazon, Facebook, and Instagram, where each user sees personalized content after logging in. Answer 9 -- Five commonly used web browsers are Google Chrome, Mozilla Firefox, Microsoft Edge, Apple Safari, and Opera. Each browser uses a rendering engine to display web pages. Google Chrome, Microsoft Edge, and Opera use the Blink rendering engine, which is known for its speed and performance. Mozilla Firefox uses the Gecko rendering engine, which focuses on web standards, privacy, and flexibility. Apple Safari uses the WebKit rendering engine, which is optimized for Apple devices and provides efficient performance and power management. Although rendering engines perform the same basic function, they differ in speed, compatibility, optimization, and implementation of web standards. Answer 10 -- The basic web architecture consists of a client, web server, APIs, and a database. The client sends an HTTP request to the web server. The server communicates with APIs when necessary and retrieves data from the database. After processing the request, the server sends the response back to the client, where the browser displays the requested information.
